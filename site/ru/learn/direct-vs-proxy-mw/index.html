Прямая и прокси-Mw

Начиная с версии 0.2 все b-значения в атласе рассчитываются только по моментным магнитудам ISC-GEM, измеренным непосредственно по сейсмическому моменту, а «прокси»-значения Mw, пересчитанные из других шкал, исключаются.

Интерактивная диаграмма · Реальный пример из атласа →

Простое объяснение

ISC-GEM приводит для каждого землетрясения Mw. Для большинства событий с 1976 г. эта Mw измерена по волновым формам (проект Global CMT). Для остальных она пересчитана из mb или Ms по формуле — это прокси.

Пересчёт — это обоснованная догадка с разбросом. Когда много таких угаданных магнитуд оказывается у нижней границы выборки, они меняют форму распределения по размерам, и b-значение сдвигается вместе с ней.

Поэтому теперь атлас оставляет только измеренные. Признак, по которому он их отличает, — неопределённость, указанная при каждой магнитуде: у измеренных Mw она наименьшая, у прокси — больше.

Пример из жизни

Представьте опрос о росте людей, где большинство измерили рулеткой, а рост некоторых оценили по размеру обуви. В среднем оценки могут быть неплохими, но они размывают «хвосты», и статистика о том, как быстро становятся редкими высокие люди, окажется неверной.

Технические подробности

Правило: событие ISC-GEM 1976–2021 гг. входит в выборку для b, только если указанная для него неопределённость Mw не больше {magerr}, то есть это прямая моментная магнитуда. Частоты, числа событий, Mc(t), слои событий и сравнение с Michael (2014) используют все события. Минимальные пороги Mc по периодам пересчитаны по той же прямой выборке, так что пороги и выборка согласованы.

Почему неопределённость указывает на прямую Mw: в копии ISC-GEM в USGS ComCat нет флага «прямая/прокси», но в 1976–2021 гг. ни у одного события нет неопределённости между 0.10 и 0.20, а почти все события, сопоставленные в ComCat с магнитудой Global CMT, имеют 0.10 (docs/method.md §2.1).

Почему не исправлять, а исключать: гауссовы ошибки магнитуд постоянной величины не смещают b (Tinti & Mulargia 1985). Избыток b у прокси намного больше, чем можно объяснить шумом; он возникает из-за того, какие именно события получили прокси, и из-за регрессионного пересчёта, который смещает b (Castellaro et al. 2006).

Цена и открытый вопрос: примерно одно событие из восьми за 1976–2021 гг. выпадает из выборки для b, минимальный порог для мелких событий в 1976–2003 гг. повышается на 0.1, и критерий качества проходит меньше ячеек. В ячейках, показанных в обеих версиях, b немного снизилось, тогда как b-positive почти не изменилось; часть этого снижения могут давать события чуть выше порога, пропущенные GCMT. Этот вопрос не решён.
