Распределение по магнитудам

Распределение по магнитудам (FMD, график повторяемости) показывает, сколько землетрясений каждого размера содержит каталог; именно по нему определяют и Mc, и b-значение.

Интерактивная диаграмма · Реальный пример из атласа →

Простое объяснение

Разбейте землетрясения какого-то места на классы по размеру шириной 0.1 единицы магнитуды и посчитайте число событий в каждом. Эта таблица и есть FMD.

Её можно изобразить двумя способами. Некумулятивно: число событий в каждом классе. Кумулятивно: число событий не меньше данного размера, N(≥ M). Кумулятивная кривая более гладкая, потому что каждая её точка включает все более сильные события.

На обычной оси числа событий кривая обрывается вниз, и сильные события сливаются с нулевой линией. На логарифмической оси, где каждая линия сетки в десять раз больше предыдущей, часть выше Mc становится прямой линией. Эта прямая и есть закон Гутенберга–Рихтера.

Пример из жизни

Это как подсчёт монет в копилке по номиналу: много мелких монет, меньше крупных. Нарисуйте, сколько монет стоят «не меньше данной суммы», на шкале, которая на каждом шаге умножается на десять, и закономерность проявится в виде прямой линии.

Технические подробности

При группировке магнитуд с шагом ΔM = 0.1 некумулятивное FMD — это n(Mᵢ), число событий с M в [Mᵢ − ΔM/2, Mᵢ + ΔM/2), а кумулятивное FMD — N(≥ Mᵢ) = Σ_{j ≥ i} n(Mⱼ). Выше Mc оба подчиняютсяlog₁₀ N(≥ M) = a − b · Mа некумулятивные числа имеют тот же наклон и меньший свободный член.

Аппроксимация: атлас никогда не подбирает b методом наименьших квадратов по точкам графика (точки не независимы, а числа событий при больших магнитудах крошечные); он использует оценку максимального правдоподобия (см. «b-значение Гутенберга–Рихтера»).

Данные: файлы с подробностями по ячейкам содержат некумулятивное FMD по классам глубины для ISC-GEM (выборка для b, с v0.2 — прямые Mw) и для ComCat в исходном виде. Панель ячейки рисует кумулятивное FMD на логарифмической оси с линией Mc, а скачиваемый CSV содержит числа событий и кумулятивные числа по интервалам.

Осторожно: при нескольких сотнях событий верхний «хвост» зашумлён, и отдельные сильные события образуют длинную горизонтальную ступеньку. Marzocchi et al. (2020) показывают, что b по малым выборкам смещено и коррелирует с наибольшей магнитудой в выборке.
