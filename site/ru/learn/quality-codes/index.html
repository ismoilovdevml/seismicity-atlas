Коды качества A, B, C и «недостаточно»

Каждая ячейка получает код качества — A, B, C или «недостаточно» — по числу событий и ширине 95 % интервала относительно b, а b-значение показывается только для A и B.

Интерактивная диаграмма · Реальный пример из атласа →

Простое объяснение

У атласа одно жёсткое правило: никакого b-значения без его интервала и кода качества.

Если выше порога полноты слишком мало землетрясений, ячейка получает код «недостаточно». Если событий достаточно, но интервал всё ещё очень широк по сравнению с самим b, ячейка получает код C и b скрывается: число, которое может оказаться чем угодно в широком диапазоне, вводило бы в заблуждение. Узкие интервалы дают A, умеренно узкие — B.

Поэтому серые и заштрихованные области на карте — не недоделанная работа. Это честный ответ для глобального каталога умеренных и сильных землетрясений.

Пример из жизни

Метеостанция, которая в прошлом году передала данные только за два дня, не может дать надёжное среднегодовое значение. Атлас скорее оставит графу пустой и объяснит почему, чем напечатает догадку.

Технические подробности

Правило (manifest.json, method.quality): не меньше 50 событий выше порогов для каждого события, иначе insufficient; затем A, если бутстреп-интервал 95 % не шире 0.30 × b (b — точечная оценка ячейки), B — если не шире 0.50 × b, иначе C (b скрыто, публикуется только ширина).

Почему относительно b (с выпуска 0.5.0; раньше пороги задавались абсолютной шириной): интервал растёт вместе с самим b, примерно как 3.92 × b/√n, поэтому абсолютный порог оставлял ячейки с низким b и скрывал ячейки с высоким b при том же числе событий. На синтетических ячейках с 70 событиями выше известного порога старое правило показывало 98 % ячеек с b = 0.8 и 2 % ячеек с b = 1.5, а показанное b ячеек с b = 1.5 в среднем равнялось 1.24; относительное правило показывает от 73 до 77 % при любом b, и среднее по показанным ячейкам отличается от истинного b не более чем на 0.02 (tests/test_atlaslib.py). При одинаковом общем числе событий ячейки с высоким b всё же проходят реже, потому что выше MAXC + 0.2 лежит меньшая доля их событий.

Почему ширина, а не только n: одно и то же n может давать разную ширину, если Mc плохо определена или выборка смешивает периоды; бутстреп-ширина включает неопределённость Mc. Флаг устойчивости к порогу (unstable) добавляется, когда b при пороге + 0.2 и + 0.4 в обоих случаях выходит за интервал с одной и той же стороны.

Условные обозначения на карте: A — полный цвет, B — тот же цвет с пониженной непрозрачностью, C — штриховка, «недостаточно» — светло-серая заливка. Легенда показывает, сколько ячеек проходят критерий качества.

Ограничение: критерий качества контролирует точность (разброс), а не отсутствие систематической ошибки. Ячейка может иметь код A и всё равно быть смещённой (например, из-за неверного порога), а соседние ячейки A имеют общие события (Wiemer & Wyss 2002; Marzocchi et al. 2020).
