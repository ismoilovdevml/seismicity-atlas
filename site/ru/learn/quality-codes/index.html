Коды качества A, B, C и «недостаточно»

Каждая ячейка получает код качества — A, B, C или «недостаточно» — по числу событий и ширине 95 % интервала, а b-значение показывается только для A и B.

Интерактивная диаграмма · Реальный пример из атласа →

Простое объяснение

У атласа одно жёсткое правило: никакого b-значения без его интервала и кода качества.

Если выше порога полноты слишком мало землетрясений, ячейка получает код «недостаточно». Если событий достаточно, но интервал всё ещё очень широк, ячейка получает код C и b скрывается: число, которое может оказаться чем угодно в широком диапазоне, вводило бы в заблуждение. Узкие интервалы дают A, умеренно узкие — B.

Поэтому серые и заштрихованные области на карте — не недоделанная работа. Это честный ответ для глобального каталога умеренных и сильных землетрясений.

Пример из жизни

Метеостанция, которая в прошлом году передала данные только за два дня, не может дать надёжное среднегодовое значение. Атлас скорее оставит графу пустой и объяснит почему, чем напечатает догадку.

Технические подробности

Правило (manifest.json, method.quality): не меньше {nMin} событий выше порогов для каждого события, иначе insufficient; затем A, если бутстреп-интервал 95 % не шире {wA}, B — если не шире {wB}, иначе C (b скрыто, публикуется только ширина).

Почему ширина, а не только n: одно и то же n может давать разную ширину, если Mc плохо определена или выборка смешивает периоды; бутстреп-ширина включает неопределённость Mc. Флаг устойчивости к порогу (unstable) добавляется, когда b при пороге + 0.2 и + 0.4 в обоих случаях выходит за интервал с одной и той же стороны.

Условные обозначения на карте: A — полный цвет, B — тот же цвет с пониженной непрозрачностью, C — штриховка, «недостаточно» — светло-серая заливка. Легенда показывает, сколько ячеек проходят критерий качества.

Ограничение: критерий качества контролирует точность (разброс), а не отсутствие систематической ошибки. Ячейка может иметь код A и всё равно быть смещённой (например, из-за неверного порога), а соседние ячейки A имеют общие события (Wiemer & Wyss 2002; Marzocchi et al. 2020).
