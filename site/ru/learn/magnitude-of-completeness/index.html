Магнитуда полноты (Mc)

Магнитуда полноты Mc — наименьшая магнитуда, выше которой каталог регистрирует практически все землетрясения в данном месте и за данный период.

Интерактивная диаграмма · Реальный пример из атласа →

Простое объяснение

Сейсмические сети пропускают слабые землетрясения: те слишком слабы, чтобы их зарегистрировало достаточно станций, или теряются в коде более сильного события. Начиная с некоторого размера ничего уже не пропускается. Этот размер и есть Mc.

Любая статистика, которая считает землетрясения по размеру, включая b-значение, должна использовать только события с магнитудой не ниже Mc. Ниже неё число событий падает из-за сети, а не из-за Земли.

Mc меняется во времени и в пространстве. За десятилетия сети улучшились, поэтому у того же региона сегодня Mc ниже, чем в 1980 г. В океанах вдали от станций Mc выше, чем на хорошо оснащённой суше.

Пример из жизни

Рыболовная сеть с фиксированной ячейкой ловит каждую рыбу крупнее отверстий и лишь часть более мелких. Подсчёт мелкой рыбы в сети говорит о сети, а не о море. Mc — это размер ячейки сети.

Технические подробности

Оценка: максимальная кривизна плюс 0.2 (MAXC + 0.2, Woessner & Wiemer 2005) по магнитудам, сгруппированным с шагом 0.1. MAXC — интервал с наибольшим числом событий; эта оценка обычно занижает Mc, отсюда +0.2. Для глобального сравнения рассчитываются также метод согласия (GFT, Wiemer & Wyss 2000) и метод устойчивости b (MBS); MAXC и GFT обычно дают заниженные значения, а MBS — завышенные, так что вместе они ограничивают Mc с двух сторон (Mignan & Woessner 2012).

Полнота, меняющаяся во времени: для 1976–2003 и 2004–2021 гг. глобальный минимальный порог для каждого класса глубины принимается равным max(MAXC + 0.2, MBS) по всем событиям с прямой Mw этого периода. Порог каждого события — thrᵢ = max(Mc_cell, floor(period of event i)). Ячейка может повысить порог, но никогда не опустить его ниже минимального.

b с порогами для каждого события: поскольку превышение магнитуды над любым порогом распределено экспоненциально с одним и тем же β, β̂ = n / Σ (mᵢ − (thrᵢ − ΔM/2)), b = β̂ / ln 10(Aki-Utsu с Mc для каждого события). Единый низкий порог для периодов с разной полнотой смещает b вниз.
